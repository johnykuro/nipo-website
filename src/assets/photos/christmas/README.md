# Christmas campaign imagery

These unchanged image masters are copied from `output/imagegen/nipo-christmas-v1/`.
They were created using image generation from NIPO food and wine references on 18 September 2026.
Exact prompts, source details and checksums are retained in that collection's `prompts.json`,
`manifest.json` and `README.md`.

The images depict imagined festive tabletop settings, not documented restaurant Christmas decor.
The steak photograph is atmospheric campaign imagery, not a photograph of the festive fillet dish.
Astro's existing `Photo` component generates responsive AVIF/WebP derivatives at build time.

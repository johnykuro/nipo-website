# NIPO Christmas imagery — first review

Four AI-generated seasonal images based on NIPO food and wine imagery, including the supplied IMG_5534.jpg dish photograph. Created with the built-in image generation tool on 18 September 2026. These are imagined festive tabletop settings, not photographs of the restaurant's Christmas decor. Website integration is not included in this review collection.

| File | Intended placement | Composition |
| --- | --- | --- |
| `christmas-steak-hero.png` | Christmas page hero | Wide landscape, dish on right with space for a heading on left |
| `christmas-salmon-sushi.png` | Festive food/menu section | Portrait, five salmon rolls on the existing bronze platter |
| `christmas-wine-pour.png` | Christmas parties or booking section | Portrait, two red wine glasses and pouring bottle neck |
| `christmas-braised-shank.png` | Festive dining or menu section | Portrait, braised shank on mash with jus, crisp onions and microgreens in the original striped bowl |

All four use dark walnut, evergreen, champagne-gold baubles, burgundy linen and warm candlelight. Food identity, portion and presentation were visually compared with the reference images. No seasonal food ingredients have been added. The wine image retains two coherent glasses, modest fills and a single pouring stream. The additional shank image's exact prompt is in `christmas-braised-shank-prompt.md`.

PNG files are native generated masters, not upscaled. Actual dimensions and hashes are in `manifest.json`; requested target sizes are recorded in the exact prompts in `prompts.json`. Sources and existing website images remain unchanged.

Use the hero at its native landscape ratio with a subtle dark overlay behind ivory copy. For a mobile layout, place copy above the photograph or use the portrait food image; a tight centre crop of the wide hero would lose part of the dish. Portrait images work best at 4:5 with captions outside the image.
